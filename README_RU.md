# Красный Квадро — Retro Runner

3D-прототип мобильной игры в Godot 4.3: вертикальный формат 9:16, автоматическое движение, три полосы, трамплин, прыжок, front flip, свайпы и базовый скоринг.

## Требования

- Godot 4.3 или совместимая версия 4.x;
- для Android-экспорта — Android SDK, Build Tools и JDK 17.

## Управление

| Действие | Клавиатура | Мобильное управление |
|---|---|---|
| Перейти влево | `A` или стрелка влево | Свайп влево |
| Перейти вправо | `D` или стрелка вправо | Свайп вправо |
| Трюк | `Space` | Автоматически при попадании на трамплин |
| Пауза | `Escape` | — |
| Перезапуск | `R` | — |

Прыжок запускается автоматически при точном попадании на трамплин. Успешное приземление начисляет бонус `+100` к счёту.

## Запуск

Откройте проект в Godot и запустите `main.tscn`. Для быстрой проверки репозитория выполните:

```bash
./validate_project.sh
```

Скрипт проверяет ключевые инварианты проекта; импорт и сборка выполняются в GitHub Actions.

## Android APK

Workflow `.github/workflows/android-apk.yml` запускается вручную или при push в `main`/`master`. Он импортирует проект в headless-режиме, выполняет проверки, собирает debug APK и публикует его как GitHub Actions artifact.

Текущая конфигурация предназначена для разработки: используется debug-подпись и архитектура `arm64-v8a`. Для публикации в магазине необходимо добавить отдельный release keystore через GitHub Secrets и настроить release preset.

## Текущий статус

Реализованы:

- процедурная сцена города, дороги и трамплина;
- три полосы и управление свайпами/WASD/стрелками;
- прыжок и вращение квадроцикла;
- базовые коллайдеры игрока, дороги, зданий и трамплина;
- сохранение бонуса за успешный трюк;
- пауза и перезапуск;
- автоматическая Android-сборка и invariant-проверки.

Ограничения прототипа:

1. Не реализованы полноценные столкновения с препятствиями и состояние game over.
2. Город и трасса пока состоят из простых процедурных примитивов.
3. Нет полноценного меню, сохранения рекорда и release-подписи.
4. Модель квадроцикла и персонажа пока заменена примитивной геометрией.
