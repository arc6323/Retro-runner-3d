# Неоновая Пустошь

Вертикальный 3D-прототип мобильного endless runner в Godot 4.3. Главный герой — антропоморфный волк Рэд, который выезжает на красном квадроцикле в ночной город.

## Что реализовано

- живая стартовая сцена на обочине вместо традиционного меню;
- запуск касанием героя;
- посадка и выезд на трассу;
- управление жестами без экранных кнопок;
- квадроцикл остаётся в центре, дорожный мир смещается;
- ночное небо, туман, тёплые фонари и более плотная застройка;
- Рэд смотрит по сторонам, дышит, наклоняется в поворот, шарф реагирует на скорость;
- камера преследования с отдалением перед трамплином и тряской при приземлении;
- прыжок только с рампы, трюк в воздухе, ускорение, столкновения и рекорд;
- русскоязычный HUD, который тянется по якорям экрана;
- автоматическая сборка Android APK через GitHub Actions.

## Управление на мобильном устройстве

| Жест | Действие |
|---|---|
| Касание Рэда на стартовом экране | Начать заезд |
| Свайп влево или вправо | Смена полосы |
| Свайп вверх у рампы | Прыжок |
| Касание в воздухе | Трюк |
| Двойное касание | Короткое ускорение |
| Касание после столкновения | Начать заново |

Прыжок свайпом вверх в чистом поле больше не работает — только на рампе.

## Клавиатура для отладки

- `A` и `D` — смена полосы;
- `Space` — прыжок у рампы или трюк в воздухе;
- `Escape` — пауза;
- `R` — возврат к стартовой сцене.

## Запуск

Откройте проект в Godot 4.3 и запустите `main.tscn`.

```bash
./validate_project.sh
```

Рекорд пишется в `user://neon_wasteland.cfg`.
