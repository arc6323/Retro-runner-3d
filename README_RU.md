# Неоновая Пустошь

Вертикальный 3D-прототип мобильного endless runner в Godot 4.3. Главный герой — антропоморфный волк Рэд, который выезжает на красном квадроцикле в поток ночного неонового города.

## Что реализовано

- живая стартовая сцена на обочине вместо традиционного меню;
- запуск касанием героя;
- короткая последовательность посадки и выезда на трассу;
- управление жестами без экранных кнопок;
- квадроцикл остаётся в центре, а дорожный мир смещается относительно него;
- передние колёса поворачиваются, герой и транспорт наклоняются в сторону манёвра;
- камера плавно отходит назад и вверх перед трамплином;
- прыжок, воздушный трюк, ускорение и начисление очков;
- русскоязычные стартовые подсказки и HUD;
- движущийся трафик и столкновение с автомобилями;
- отдельные GLB-модели Рэда в стоячей и водительской позах;
- детальная GLB-модель Street Quad с подвеской, светом и четырьмя управляемыми колёсами;
- автоматическая сборка Android APK через GitHub Actions.

## Управление на мобильном устройстве

| Жест | Действие |
|---|---|
| Касание Рэда на стартовом экране | Начать заезд |
| Свайп влево или вправо | Смена траектории через смещение мира |
| Свайп вверх | Прыжок |
| Касание в воздухе | Трюк |
| Двойное касание | Короткое ускорение |
| Касание после столкновения | Начать заново |

На игровом экране нет виртуального джойстика и кнопок управления.

## Клавиатура для отладки

- `A` и `D` — смена траектории;
- `Space` — прыжок или трюк;
- `Escape` — пауза;
- `R` — возврат к стартовой сцене.

## Запуск

Откройте проект в Godot 4.3 и запустите `main.tscn`. Для проверки ключевых инвариантов выполните:

```bash
./validate_project.sh
```

## Android APK

Workflow `.github/workflows/android-apk.yml` запускается при push в `main`/`master` и вручную. Он импортирует проект в headless-режиме, выполняет invariant-проверки, собирает debug APK и публикует artifact.

Для публикации приложения понадобится отдельная release-подпись через GitHub Secrets.

## Архитектура прототипа

Игрок находится в `PlayerAnchor` около центра экрана. Дорога, трафик, здания и трамплин находятся внутри `WorldPivot`. При смене логической полосы смещается `WorldPivot`, а не позиция игрока. Это создаёт ощущение руления при стабильной композиции мобильного экрана.

Состояния запуска и игры:

```text
ROADSIDE_IDLE → MOUNTING → MERGING → RUNNING
                                      ↓
                              PAUSED / GAME_OVER
```

Модели находятся в `assets/models/`. Старые функции построения Рэда и квадроцикла из примитивов удалены. Godot управляет именованными узлами передних колёс, вращением всех четырёх колёс, головой и хвостами шарфа.
