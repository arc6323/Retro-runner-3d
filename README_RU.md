# Красный Квадро — Retro Runner

Первый 3D-прототип концепции: вертикальный 9:16, автодвижение, три полосы, трамплины, автоматические 5 вариантов воздушных выкрутасов, свайпы и базовый скоринг.

## Важно
В этой среде сейчас нет установленного Android SDK/Build Tools, поэтому готовый APK здесь собрать не удалось. Проект подготовлен под Godot 4.x и может быть экспортирован в Android APK/AAB в Godot.
